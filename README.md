# Sistema de Leilões

## Sobre o Projeto
Este é um sistema informatizado em desenvolvimento para gerenciar as rotinas de uma casa de leilões. O projeto tem como objetivo principal controlar e registrar as operações do negócio, aplicando práticas de segurança, qualidade de software e controle de versão.

## Tecnologias Utilizadas
* Java
* MySQL (Banco de Dados)
* Git e GitHub (Versionamentoa 
)
